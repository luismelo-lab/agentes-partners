# Minutas-esqueleto: leia antes de usar

**Estas minutas NÃO são modelos aprovados.** São esqueletos de estudo montados pelo Departamento de Contratos virtual em 22/10/2026 (onda sênior, D93). Cada cláusula traz um comentário do especialista e a marca **[validar com o Jurídico humano]**.

## Para que servem
- Levar à área real de Contratos e ao Jurídico humano uma estrutura completa, para a aprovação ser mais rápida.
- Orientar o Montador de Minuta sobre o que perguntar quando o modelo aprovado não cobre um caso.
- Nunca para enviar a cliente ou parceiro.

## Regra de uso (inegociável)
1. O modelo aprovado de verdade fica em `~/agentes-partners/departamentos/contratos/modelos/`, com o nome `AAAA-MM-DD-<tipo>-v<N>` e, no topo, quem aprovou e quando. Em 22/10/2026 a pasta estava vazia.
2. Enquanto não houver modelo aprovado, a entrega é **ficha de dados + pontos para o Jurídico** (`references/montador-minuta.md`). O esqueleto só pode ser anexado como "proposta de estrutura".
3. Todo texto destes arquivos é `[SUGESTÃO — VALIDAR JURÍDICO]`.
4. Nenhum esqueleto promete valor, prazo ou êxito. Na alíquota zero, a via é sempre PER, nunca DCOMP (D14).
